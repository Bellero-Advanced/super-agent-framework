# M0 — ระบบ SAF ทำงานได้ใน repo นี้

## เป้าหมาย

พิสูจน์ว่ารอบการ์ดของ SAF ใช้ได้ที่นี่ก่อนเริ่มงานจริง: อ่านแผนได้ เอกสารตรงความจริง ไม่มีค่าลับในไฟล์ที่ track
และ session ใหม่เห็นการ์ดปัจจุบัน

## ขอบเขต

- การ์ดเดียว (T-M0-01) ที่รันการตรวจตัวเองของ SAF ผ่านรอบการ์ดจริง
- ไม่แก้โค้ดของผลิตภัณฑ์

## ความเสี่ยง

- ตรวจของโปรเจคที่ล้มอยู่แล้วก่อนตั้งค่า — แก้ในการ์ดของมันเอง ห้ามลดประตู
