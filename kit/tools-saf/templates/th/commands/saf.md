# /saf — ส่งงานตามรอบการ์ด

คำขอ: $ARGUMENTS

## 1. หาที่ของงาน

1. อ่านสรุปที่ hook ฉีดมา (หรือ `docs/plan/STATE.md`): milestone ที่ active · การ์ดที่กำลังทำ · การ์ดถัดไป
2. จับคู่คำขอกับการ์ดใน `docs/plan/tasks/`:
   - มีการ์ดแล้ว → ใช้การ์ดนั้น
   - ยังไม่มีการ์ดแต่อยู่ใน milestone ที่ active → ให้ `designer` เขียนการ์ดก่อน (`/saf-plan`) แล้วทำต่อ
   - ไม่อยู่ใน milestone ไหน → บอก{{owner}}หนึ่งบรรทัดและถามว่าจะเพิ่มไหม · ห้ามสร้างงานเอง
   - บั๊ก → `/saf-fix` · ทดสอบอย่างเดียว → `/saf-test` · ความปลอดภัย → `/saf-protect`
3. ดู `depends` ของการ์ด — ที่ยังไม่ผ่านต้องทำก่อน

## 2. ทำการ์ด

| ขั้น | ใคร | คำสั่ง |
|---|---|---|
| เริ่ม | session หลัก | `{{cmd.taskStart}}`{{#if lanesOn}} (บทบาทสายโค้ด → `{{cmd.taskStartLane}}`){{/if}} |
| ลงมือ | agent ตาม `role` ของการ์ด | แตะเฉพาะไฟล์ใน `touch` |
| ตรวจ | agent เดิม | `{{cmd.taskVerify}}` จนผ่าน |
| เทียบสเปก | `spec-reviewer` (อ่านอย่างเดียว){{#unless reviewEvery}} — การ์ดขนาด M · การ์ด S ตรวจรวมที่ประตูออก{{/unless}} | ส่งรหัสการ์ด{{#if tokenSaving.reviewerDiff}}และไฟล์ diff{{/if}} |
| ทดสอบจริง | `qa-runner` | เมื่อการ์ดแตะ UI · multiplayer · ประสิทธิภาพ |
| ลงงาน | session หลัก | commit{{#if lanesOn}} · การ์ดสาย → `{{cmd.taskMerge}}`{{/if}} |

การ์ดที่ไม่ขึ้นต่อกันทำขนานได้{{#if lanesOn}} — `{{cmd.taskNext}}` บอกชุดที่ปลอดภัย{{/if}}

## 3. รายงาน

ตอบเป็น{{chatLanguageName}} เรียกผู้ใช้ว่า "คุณ" แทนตัวเองว่า "ผม" · ผลลัพธ์ก่อน: อะไรเปลี่ยนสำหรับผู้ใช้ · การ์ดไหน ·
ผล verify พร้อมตัวเลขจริง · เรื่องที่{{owner}}ต้องตัดสิน (ถามครั้งเดียว พร้อมตัวเลือกและคำแนะนำ) · ไม่ dump stack trace

ห้ามรายงานว่า "เสร็จ" ถ้า `task:verify` ยังไม่ผ่าน
