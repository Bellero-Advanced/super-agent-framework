# /saf-fix — หลักฐานก่อน แล้วค่อยแก้

ปัญหา: $ARGUMENTS

ทำตาม skill `debug-protocol`:

1. **ทำให้เกิดซ้ำ** — คำสั่งหรือขั้นตอนที่แน่นอนพร้อมผลจริง · ทำซ้ำไม่ได้ → หาหลักฐานเพิ่ม ห้ามเดา
2. **หลักฐาน** — log · test ที่ล้ม · input ที่เล็กที่สุด · แยกสิ่งที่รู้กับสิ่งที่สมมติ
3. **วินิจฉัย** — ต้นเหตุหนึ่งประโยคพร้อมหลักฐานที่พิสูจน์
4. **แก้** — ที่ต้นเหตุ ไม่ใช่อาการ · เพิ่ม test ที่ล้มก่อนแก้และผ่านหลังแก้
5. **พิสูจน์** — รันคำสั่งที่ล้มอีกครั้งพร้อม test ที่เกี่ยวข้อง แนบตัวเลขจริง

ลงที่ไหน:

- อยู่ในการ์ดที่กำลังทำ → เป็นส่วนของการ์ดนั้น (อยู่ใน `touch`)
- ไม่อยู่ → designer เขียนการ์ดแก้เล็กๆ (`/saf-plan`) แล้วเดินตาม `{{cmd.taskStart}}` → `{{cmd.taskVerify}}`
- test ที่ผลไม่นิ่งคือบั๊ก — แก้ความไม่นิ่ง ห้ามรันซ้ำจนเขียว

รายงานเป็น{{chatLanguageName}}: ต้นเหตุ · วิธีแก้ · หลักฐาน · ไม่ dump stack trace
