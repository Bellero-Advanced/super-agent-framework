# T-M1-02 — HTTP API — GET /todos, POST /todos, PATCH /todos/:id/done

## Why

## What to do

- `src/server.mjs`: `createServer(store = createStore())` with `node:http`, JSON in and out; `npm start` listens on
  `PORT` (default 3000) when the file is run directly
- 404 for unknown ids and unknown paths
- integration tests start the server on port 0 and use `fetch` — named with TODO-AC-03 and TODO-AC-05
