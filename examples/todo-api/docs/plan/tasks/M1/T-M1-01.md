- `src/store.mjs`: `createStore()` returning `{ add(title), list(), markDone(id) }` — `markDone` returns the todo or `null`
- ids count from 1 per store; `list()` returns copies so callers cannot change stored todos
- tests named with TODO-AC-01 and TODO-AC-02
