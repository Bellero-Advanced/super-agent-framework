# create-saf

Sets up [SAF — Super Agent Framework](https://github.com/Bellero-Advanced/super-agent-framework) in a project.

```bash
npx create-saf            # in your project folder
npm create saf            # same thing
npx create-saf my-app     # set up a new folder
```

Then open Claude Code in that folder and type `/saf-setup`. Options are the same as `saf init`
(`--answers <file.json>`, `--adopt`, `--no-adopt`) — see the
[install guide](https://github.com/Bellero-Advanced/super-agent-framework/blob/main/docs/install.md).
