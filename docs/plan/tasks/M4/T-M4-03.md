# T-M4-03 — A reinstall keeps the plan where it is

## Why

Proposed card A, part 3 — review note 02/F2. Moved from M3 (was T-M3-26) to M4 by owner order 2026-11-25. Written as
size S; read as M under D-021 (the work is unchanged). On a first run (no `.saf/manifest.json`) adopt moves every file
under `docs/plan/` without a manifest entry into `docs/archive/pre-saf/`. After a reinstall (manifest deleted, plan
intact) the evidence leaves `docs/plan/` and every card looks not done — moved, not lost, but the project's status is
gone until someone moves it back.

**Waits for the owner:** [D-019](../../../DECISIONS.md) is `proposed` (options a · b · c, recommended a). The card is
written for option (a). Do not start it until the row says decided; if the owner picks (b) or (c), the designer
rewrites this card and rule 37 first. The first "Done when" command fails while the row is not decided.

[Rule 37](../../../specs/setup-rerun.md#reinstall-into-a-project-that-already-has-a-plan-waits-for-d-019).
