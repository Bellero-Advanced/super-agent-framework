# T-M3-24 — Setup and upgrade test gaps

## Why

Proposed card E of [M3 "Carried to M3"](../../milestones/M3.md#carried-to-m3), part 1 — tests only, for behaviour that
already works (or that T-M3-16 · T-M3-17 · T-M3-21 settled). Review notes:

- 18/4 — upgrade: BOM kept · schema-invalid `saf.config.json` · non-object root or `scripts` · "unchanged" asserted on
  every top-level key, not only `scripts` (`upgrade-scripts.test.mjs`, UPG-AC-04 / -05)
- 20/N2 — "an unedited living file is still updated" asserts nothing was kept; assert it was really updated
  (`report.written` includes it and the bytes changed) (`setup-rerun.test.mjs`, RERUN-AC-01)
- 21/6 — the diff property test: assert `-` and context lines match the old text, check `newStart` / `newLines`, add
  pairs without a final newline and with CRLF (`setup-diff.test.mjs`, RERUN-AC-05)
- 21/7 — `--keep` on a first run with adopt; `--keep` of a file already equal to the new version ("no differences")
  (`setup-diff.test.mjs`, RERUN-AC-06)
- 02/N4 — tidy-up: `const bad = cli(empty, "--dry-run")` expects 0 (rename); `assert.deepEqual(x.length > 5, true)` →
  `assert.ok` (`setup-dry-run.test.mjs`)
- 27/N4 — `settings.json` with a `null` / string / number root; both files unreadable; the `.1` archive suffix after a
  real run, not only in the plan (`settings-archive.test.mjs`, RERUN-AC-08 / -09)
- 01/8 — `refreshKitFiles`' template fallback warning (upgrade with a `docLanguage` whose template is missing) has no
  test (`doc-languages.test.mjs`, LANG-AC-02). (01/9 is dropped: the old-vs-new comparison was a one-off untracked
  script for the T-M2-01 refactor; the old code no longer exists to compare with.)

## What to do

- add or tighten the tests above in the files in `touch`; each new test name carries the scenario id it strengthens
- a test that fails shows a real bug: stop, log it with `npm run task:friction -- add …` if it is a framework bug, and
  tell the main session — do not change code in this card
- no change outside `test/unit/`

## Out of scope

- Code changes of any kind · choices, gate and lane test gaps (T-M3-25)
