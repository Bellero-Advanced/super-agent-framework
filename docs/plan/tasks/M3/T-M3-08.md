# T-M3-08 — Self-fix cards: field, plan check, cap, auto-close

## Why

The owner pre-approved SAF fixing itself (D-017). The approval must be bounded by rules the engine checks, not by an
agent's restraint: only proven small bugs, one size, a test, a cap per milestone, and a switch that is off for users.
[Spec rules 18–22](../../../specs/friction-log.md#self-fix-cards-t-m3-08).

## What to do

- schema + `config.mjs` defaults: `workflow.selfFix` enum `off` · `on`, default `off`; `choices.mjs`: `NOT_ASKED`
  line (en + th) saying what it allows and that the owner's Go is skipped only inside the cap
- `friction.mjs`: `SELF_FIX_LIMITS` (`perMilestone`); `selfFixIssues(plan)` checks every condition of rule 19 and
  returns one issue per broken condition, naming it
- `plan.mjs`: `parseCard` reads `self_fix`; `validatePlan` adds `selfFixIssues`
- `task.mjs` `verifyCard`: when a `self_fix` card passes, append `→ fixed` through `appendClose` (main folder; in a
  lane the line is appended by `task:merge` after the merge succeeds — same function)
- `/saf` templates (en, th), shown only when `workflow.selfFix` is `on` (flag from `templateData` in
  `generate.mjs`): a "Self-fix" section with the steps of rule 20 (draft → card file → append its id to the active
  milestone's `cards:` only → `task:friction close <F> carded <id>` → normal loop, failing test first) and rule 22
  (anything else waits for the designer and the owner's Go)
- this repo: `saf.config.json` `workflow.selfFix: "on"` (D-017); `npm run saf:refresh` re-renders `/saf`
- `docs/config-reference.md` (`workflow.selfFix`), `docs/card-lifecycle.md` (the self-fix path and its limits)
- `test/unit/self-fix.test.mjs`: one test per scenario id in its name; AC-10 walks every condition of rule 19
- run `node bin/cli.mjs upgrade --dir examples/todo-api`, then `git checkout -- examples/todo-api/.claude`
- **use the `security-review` skill** while building: this card lets the AI add work without the owner's Go

## Out of scope

- writing self-fix cards automatically (the main session writes them) · kinds or cap other than D-017's
