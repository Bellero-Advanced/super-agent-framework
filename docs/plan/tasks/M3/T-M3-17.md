# T-M3-17 — No temp copy of the plan; the task template is SAF's file

## Why

Proposed card A, part 2. Review notes 02/F5 · 02/N3 · 20/N3 · 15/N6:

- `planStatus` (`generate.mjs`) copies `docs/plan` into an `os.tmpdir()` folder on every setup and dry run: a new
  failure mode when the temp folder is read-only or full, and a cost for big plans (02/F5); no test shows the folder is
  removed (02/N3 — moot once there is no folder)
- `docs/plan/tasks/_template.md` matches `LIVING_FILES`, so an edited template never gets format updates (20/N3)
- the skill and the engine detecting a re-run differently (15/N6): `SKILL.md` already names `.saf/manifest.json`
  (fixed in T-M2-22) — this card adds the test that keeps it so

[Rules 32–34](../../../specs/setup-rerun.md#reading-the-plan-the-card-template-and-the-skills-re-run-test).

## What to do

- `plan.mjs`: `loadPlan(root, config, io)` with optional `io = { read(rel), list(rel) }`; `listFiles` and `read` go
  through it; without `io` nothing changes (same results, same issues)
- `generate.mjs` `planStatus`: build the overlay from the files under `docs/plan/` on disk (minus `moved`, links
  ignored as today) plus the planned `writes`, and `.gitmodules`; call `loadPlan(root, config, overlay)`; drop
  `mkdtempSync`, `tmpdir` and the copy
- `isLiving`: a path whose last segment starts with `_` is not living
- `test/unit/setup-plan-read.test.mjs`: RERUN-AC-17, -18, -19 (ids in the names); AC-18 must fail on the code before
  this card
- `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api`, then restore
  `examples/todo-api/.claude` and `examples/todo-api/package.json`
