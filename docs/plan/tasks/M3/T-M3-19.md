# T-M3-19 — The evidence views agree

## Why

Proposed card C of [M3 "Carried to M3"](../../milestones/M3.md#carried-to-m3) — review notes 05/N1 · 05/N2 · 05/N4 ·
05/N5 · 05/N7 · 17/1 · 17/2 · 17/4. The same gate shows different words in different views: a result without `pass`
is "manual check" on the page and "failed" in the report (05/N1); a declared gate with commands and a `null` result is
"not run" in `STATE.md`, an undeclared one "manual" (17/4); the mirror's undeclared manual gate lacks the manual suffix
(17/1). Broken or hand-made evidence crashes or bloats the views: `gates` as an object throws a TypeError (05/N4), a
huge tail makes a huge page (05/N7). The page shows literal markdown backticks (05/N2) and a raw `active` on a Thai
page (05/N5). The gate-view test uses a loose substring check (17/2).

[Rules 10–14](../../../specs/evidence-viewer.md#every-view-says-the-same-about-a-gate-t-m3-19).

## What to do

- `plan.mjs`: export `gateWord(t, gate, result)` (rule 10 table) and `gateResults(gateEvidence)` (an array, `[]` for
  anything else; `loadPlan` adds one issue naming the file when `gates` is not an array); `STATE.md`, the mirror,
  `undeclaredGates`, `report.mjs` and `viewer.mjs` use them — no other place decides a gate word
- mirror: tick only "passed"; the manual suffix on every manual gate
- `viewer.mjs`: text-table strings with backticks → `<code>` (escape first, then turn backtick pairs into tags); the
  milestone status through a new `milestoneStatus` entry of the text table (en and th); tails over
  `RUN_LIMITS.tailFail` lines → the last ones plus one "N earlier lines not shown" line (new text entry, en and th)
- `test/unit/test-mode-gate-views.test.mjs`: replace `!view.includes("old")` with an exact check of the gate rows, and
  assert the no-evidence rows equal the declared rows exactly (17/2) — adjust expectations only where rule 10 changes
  a word, and name each such change in the verify notes
- `test/unit/evidence-views-agree.test.mjs`: VIEW-AC-05 and VIEW-AC-06 (ids in the names); VIEW-AC-05 must fail on the
  code before this card
- `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api`, then restore
  `examples/todo-api/.claude` and `examples/todo-api/package.json`
