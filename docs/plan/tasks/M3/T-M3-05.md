# T-M3-05 — Setup question and explanations for effort by size

## Why

A setting nobody is asked about is a setting nobody chooses. The explanation must name the real cost: S cards at a
lower effort may bounce more in review — and the report shows it. The M2 setup-choices reviews found several
explanations that were not true to the code (notes 4–9 of T-M2-13), so every sentence here is checked against
`config.mjs`, `effort.mjs` and `generate.mjs` before it is written. [Spec rules 13–14](../../../specs/effort-by-size.md#setup).

## What to do

- `choices.mjs`: move `models.effort` from `NOT_ASKED` to a group-4 `choice` row `effort` with options `fixed` ·
  `by-size`; one explanation per option in en and th (what it is · good for · cost · pick it when). Facts to state,
  each verifiable in code: `fixed` keeps one effort per role and the agent files as they are; `by-size` lowers the
  effort only for the roles and sizes in `EFFORT_BY_SIZE` and adds one agent file per changed role; S cards may bounce
  more in review; `task:report` shows review rounds by size and effort; `saf.config.local.json` can override it per
  machine; `models.overrides` still wins for a single role. No digits, no model ids, within `FIELD_MAX`
- same group, carried from M2 (review note 28/N4): the `model-preset` `max` / `balanced` / `economy` `what` says
  "Planner roles use the top model…", which stops being true once `models.planner` / `models.builder` ids are set
  under that preset (`resolveConfig` applies them with any preset) — add the exception, en and th
- `questions.md` group 4: a row with Key `models.effort`, default `fixed`
- `docs/setup-questions.md` (group 4), `docs/config-reference.md` (`models` section: `effort`, the local override,
  the variant files), `docs/roles.md` (the variant agent files and who uses them)
- `test/unit/effort-setup.test.mjs`: one test named with `EFFORT-AC-08`; SETUP-AC-01/02/05/06 stay green
- run `npm run saf:refresh` (refreshes the setup skill copy)
- write the Thai text as plain Thai; list the Thai fields in the hand-off so the native-reader pass (note 15 of
  T-M2-13) can include them
