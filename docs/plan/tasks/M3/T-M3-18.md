# T-M3-18 — task:culprit is robust

## Why

Proposed card B of [M3 "Carried to M3"](../../milestones/M3.md#carried-to-m3) — review notes 09/1 · 09/3 · 09/4 ·
09/5 · 09/6 · 09/7 · 09/8 · 09/9 on `kit/tools-saf/lib/culprit.mjs`:

- Ctrl-C leaves the temporary `culprit-*` worktree behind (no signal handler; `finally` does not run) (09/1)
- `FAIL_TAIL = 20` sits outside `RUN_LIMITS` (09/4)
- no `requireValid(plan)`; card ids go into `new RegExp` unescaped (09/5)
- "already fails before the first card" differs from the spec's words (09/6)
- the base choice by first-parent count vs. "oldest ancestor" (09/7) — the spec now defines it (rule 22); the card
  proves the code matches with a base on a merged lane branch
- nothing is printed during a long run (09/8)
- tie order (several ids in a subject, equal file overlap) unspecified (09/9) — now rule 26
- the second half of rule 21 is weakly tested (09/3) — add an assertion that the hint is absent when `deferredCards` is
  empty, inside this card's test file

[test-mode rules 22, 24–26, 31–33](../../../specs/test-mode.md#finding-the-card-that-broke-the-suite-taskculprit-m).

## What to do

- `run.mjs`: `RUN_LIMITS.culpritTail` (20); `culprit.mjs` uses it
- `task.mjs`: export `requireValid`; `findCulprit` calls it right after `loadPlan`; `saf.mjs` `culprit` case: an id not
  matching `^M\d+$` → usage line, exit 2
- `cardOf`: match ids as literal text (escape, or a token split of the subject); first id in `m.cards` order wins;
  equal overlap keeps the earlier card (assert it)
- signals: while the search runs, `SIGINT` / `SIGTERM` handlers stop the running command (the runner's kill), remove
  the worktree (`removeWorktree`), print one "interrupted" line and exit 130 / 143; remove the handlers in `finally`
- streaming: `findCulprit` passes `ctx.onOutput` to `taskRunner`; `saf.mjs` sets it to write to stdout
- `culpritLines`: rule 33 words exactly
- `test/unit/culprit-robust.test.mjs`: TMODE-AC-17, -18, -19 (ids in the names). AC-17 spawns the CLI and sends the
  signal; skip it on `win32` with a reason (POSIX signals). Real git repos as in `culprit.test.mjs`
- `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api`, then restore
  `examples/todo-api/.claude` and `examples/todo-api/package.json`

## Out of scope

- Changing the search itself or its run budget · the verify fallback reason (T-M3-20)
