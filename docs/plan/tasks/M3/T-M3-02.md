# T-M3-02 — Review rounds: task:review, reopen on fail, rounds in the report

## Why

The spec review is an agent's judgment, so the engine never learns how often a card bounced or why — the number D-016
needs to judge effort by size. Today a failed review also forces `task:start --restart` (friction F-002 of T-M3-01).
[Spec rules 1–10](../../../specs/review-rounds.md#2-rules).

## What to do

- new `kit/tools-saf/lib/reviews.mjs`: `REVIEW_KINDS`, `REVIEW_LIMITS`, `reviewsPath(id)` →
  `docs/plan/evidence/reviews/<id>.json`, `readReviews`, `recordReview(ctx, id, result, { kinds, note, area })`
  per rules 2–7; for a lane card read the branch evidence with the helper `task:merge` uses (export it from
  `task.mjs` if it is private; no behaviour change there); `fail --kind framework` calls `appendEntry` from
  `friction.mjs` (import only — do not change that file)
- `task.mjs`: a `fail` on a main-folder card writes `status: "failed"`, `reviewFailed: <round>` into its evidence,
  keeping everything else; confirm `verifyCard` then runs without `--restart` and continues the attempt count; make
  sure `startCard --restart` and `abandonCard` never touch `evidence/reviews/`
- `report.mjs` + `text.mjs` (en, th): the "Reviews" column and the totals line (rule 8)
- `bin/saf.mjs`: `task review <id> [pass|fail] [--kind …] [--note …] [--area …]`, exit 0 / 1 / 2, refused in a lane
- `config.mjs` `ENGINE_SCRIPTS` + `generate.mjs` `cmd.taskReview`; `package.json` script `task:review`;
  example `package.json` through the example upgrade
- `/saf` templates (en, th): the review step records `task:review` (pass, or fail with kinds) and says to commit the
  reviews file alone before `task:merge`; CLAUDE templates (en, th) and `CLAUDE.md`: one command line;
  `docs/card-lifecycle.md`: the review step
- the main session, after the card lands: `npm run task:friction -- close F-002 fixed T-M3-02` and commit the
  friction file alone
- `test/unit/review-rounds.test.mjs`: temp repos (a lane fixture for AC-04); one test per scenario id in its name
- run `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api`, then
  `git checkout -- examples/todo-api/.claude`

## Out of scope

- effort by size and its report table (T-M3-04) · blocking merge on a missing review · friction triage (T-M3-07)
