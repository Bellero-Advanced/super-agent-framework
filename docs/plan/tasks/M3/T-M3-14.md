# T-M3-14 — Setup and upgrade install pinned skill packs

## Why

Moved from M2 (was T-M2-23) by D-013 — last in M3's order.

`pack show` lets a person inspect a pack; this card installs the ones they pinned, and refuses changed content until a
person reviews it again. **Security-relevant:** build and review with the `security-review` skill — the writes must stay
inside `.claude/skills/<pack skill>/` and a hash mismatch must never change installed files.
[Spec rules 8–12](../../../specs/skill-packs.md#install-setup-and-upgrade).

## What to do

- schema: `skills.external` — array of `{ path: non-empty string, sha256: 64 lowercase hex }`, no extra properties;
  `config.mjs` DEFAULTS `skills.external: []`
- `kit/tools-saf/lib/choices.mjs`: `skills.external` in `NOT_ASKED` (en + th one-liners) so SETUP-AC-01 holds until
  T-M3-15 moves it into the interview
- `kit/tools-saf/lib/generate.mjs`: `skillFiles` adds, per entry, the files of `readPack(root-resolved path,
  { taken })` when valid and `packHash` equals the entry; rendered with the project data; dests under
  `.claude/skills/<skill>/` (assert the resolved dest stays inside); an entry that is invalid, missing or mismatched
  adds no planned files and its already-installed files (from the manifest `packs` record) are carried as kept so
  `retireUnplanned` never removes them for that reason; warning with the reason (mismatch: new hash + changed file
  names from comparing rendered content with the manifest); manifest gains `packs: { <name>: { path, version, sha256,
  skills } }`; works in `planSetup` (setup and dry run) and in `refreshKitFiles` (upgrade)
- `docs/config-reference.md`: `external` in the `skills` section; `docs/skills.md`: how to add a pack (submodule,
  `pack show`, the entry, what happens on a changed hash); `docs/upgrade.md`: one bullet
- `test/unit/skill-packs-install.test.mjs`: temp projects and fixture packs; one test per scenario id in its name
- run `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api`, then
  `git checkout -- examples/todo-api/.claude examples/todo-api/package.json`
- `CHANGELOG.md`: one line under `## Unreleased` (`### Added`) for what this card ships (M3 scope rule)

## Out of scope

- the interview question (T-M3-15) · fetching by URL · packs with agents, commands, rules, hooks or settings
