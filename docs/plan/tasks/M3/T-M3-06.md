# T-M3-06 — This repository uses effort by size

## Why

D-016: this repository uses `by-size` so the review-round numbers that decide the product default come from real
cards. [Spec rules 6, 8, 11](../../../specs/effort-by-size.md#2-rules).

## What to do

- `saf.config.json`: `models.effort: "by-size"`
- `npm run saf:refresh` writes the variant agents (`implementer-medium`, `designer-medium`) and re-renders `/saf` and
  `/saf-plan` with the by-size wording; check that the base agent files are byte-identical
- `CLAUDE.md` ("Open a session per role" paragraph): "effort by card size — `task:start` names the agent" instead of
  "effort fixed per role", matching what the CLAUDE template renders in `by-size` mode
- do not start other cards to try it — EFFORT-AC-06 (T-M3-04) proves which agent a size S and a size M card get

## Out of scope

- changing the product default (stays `fixed`, D-016) · any engine change

## Done when

- `node -e "const c=JSON.parse(require('fs').readFileSync('saf.config.json','utf8'));if(c.models.effort!=='by-size')process.exit(1)"`
- `node -e "const fs=require('fs');for(const r of ['implementer','designer']){const s=fs.readFileSync('.claude/agents/'+r+'-medium.md','utf8');if(!/^effort: medium$/m.test(s)||!s.includes('name: '+r+'-medium'))process.exit(1)}"`
- `npm run docs:check`
- `npm test`
