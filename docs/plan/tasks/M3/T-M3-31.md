# T-M3-31 — task:diff for the reviewer

## Why

`tokenSaving.reviewerDiff` says "give the reviewer a diff file", but no command writes one: for every M2/M3 card the
main session picked the base, excluded evidence, STATE, the mirror, engine copies and example copies, and handled lane
cards by hand — different each time, sometimes with the whole engine copy inside. Owner order 2026-11-24.
[Spec rules 1–9](../../../specs/review-diff.md#2-rules). The review types come from T-M3-29.

## What to do

- new `kit/tools-saf/lib/reviewdiff.mjs`: rules 1–7 — files from `cardFiles`, header with `cardSize`, git with
  argument arrays, new/deleted/binary files, lane card read in its worktree
- `task.mjs`: export the lane files-base helper `task:verify` uses (`laneFilesBase`) — no behaviour change
- `bin/saf.mjs`: `task diff <id>`, strict arguments, exits 0/1/2; `config.mjs` `ENGINE_SCRIPTS["task:diff"]`;
  `generate.mjs` `cmd.taskDiff`; `package.json` script; example `package.json` through `npm run saf:refresh`
- `/saf` en + th and `.claude/commands/saf.md`: the review row runs `task:diff <id>` (when `tokenSaving.reviewerDiff`)
  and gives the reviewer the card id, the review types and the path (rule 9); CLAUDE templates en + th and `CLAUDE.md`:
  one commands-block line; `docs/card-lifecycle.md`: the review step
- `test/unit/review-diff.test.mjs`: RDIFF-AC-01 … -06 (ids in the names), temp repos (a lane fixture for AC-03)
- in the verify notes: sentence → code for every changed template sentence (en and th)

## Out of scope

- Blocking merge without a review · the agent checklists themselves (T-M3-29)
