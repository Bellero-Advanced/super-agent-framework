# T-M3-35 — Sizes M and L in the engine, the hard stop, legacy S, and every rendered cap

## Why

Owner order 2026-11-25 (D-021): two sizes, M and L; S is retired because many small cards cost as many tokens as big
ones. Warn at the cap, fail at twice it so the designer splits the card. Old `size: S` cards keep working as M, and
no card file or evidence is rewritten. [Spec rules 1–16](../../../specs/card-sizes.md#2-rules). Role effort: high
(engine and templates together).

## What to do

- `config.mjs`: `SIZES` (`M`, `L`), `SIZE_CAPS` and `HARD_STOP_FACTOR` with D-021's values; `RIGOR` loses `sizes` and
  `testCaps`; `resolveConfig` fills `workflow.sizes` / `workflow.testCaps` from the table for every rigor, keeps a
  `{ M, L }` project value, drops an old `{ S, M }` value into `workflow.sizesLegacy` (rule 3); `countedSize(card)`
  (rule 4); `EFFORT_BY_SIZE` keyed `M` / `L` (rule 12 — implementer and designer M medium, L high; the other rows
  one effort for both keys, as today)
- schema `$defs/sizeCaps`: `oneOf` the new shape `{ M, L }` and the legacy shape `{ S, M }`, both keys required
- `plan.mjs` (inside `loadPlan`'s issues, where milestone status and evidence are known): rule 10's three issues;
  `parseCard` no longer refuses `S` itself
- `task.mjs`: `cardSize` uses the counted size and returns the rule-5 shape; `verifyCard` counts the size before the
  commands and stops by rule 7 (no command runs, failed attempt recorded), counts again after them, prints the rule-6
  / rule-7 lines exactly, prints the rule-3 line for each ignored legacy key; `effortLines` and `task:start` print the
  rule-9 size text; `saf.mjs`: the card report shows the hard-stop line among the failure reasons, exit 1;
  `config --check` prints the rule-3 lines
- `effort.mjs`: look up `EFFORT_BY_SIZE` with the counted size · `friction.mjs`: self-fix needs counted size M with
  the rule-13 text, the draft prints `size: M`
- `generate.mjs` `templateData`: `sizeM`, `sizeL`, `testM`, `testL`, `hardStop`; remove `sizeS`, `testS`
- templates of rule 14 (en and th): show M and L caps, the (stop) lines also the hard stop; card template and
  `T-M0-01` say `size: M`; `choices.mjs` only the rigor derived line and the `sizes` / `caps` labels (rule 15) — the
  explanation sentences are T-M3-36
- this repository and the example (rule 16): remove `workflow.sizes` / `workflow.testCaps` from both
  `saf.config.json`; `npm run saf:refresh` (re-renders the example's `CLAUDE.md`, agents, commands); bring this
  repository's `CLAUDE.md` size line, `docs/plan/README.md`, `docs/plan/tasks/_template.md`, `.claude/agents/*`,
  `.claude/rules/{plan-files,tests}.md`, `.claude/commands/saf-plan.md` and the example's rules, plan README and card
  template to the rendering; `scripts/demo.mjs` writes `size: M`
- `test/unit/card-sizes.test.mjs`: one test per scenario id in its name (SIZE-AC-01 … 09)
