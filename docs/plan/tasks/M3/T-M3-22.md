# T-M3-22 — Release-operator text follows the policies

## Why

Proposed card D, part 3 (text for users — **role effort: high**: text cards bounced at `medium` in M2, see
[M3 "Carried to M3"](../../milestones/M3.md#carried-to-m3)). Review notes:

- 14/N6 · 19/N-b — with `deploy: allowed` the generated `.claude/agents/release-operator.md` still says live changes
  happen "only on an explicit owner order" (description) and step 1 says "No order → stop"
- 19/N-a — with `push: allowed` and `autoDeployBranches` it says "Pushing is allowed" and, lines later, "Pushing
  <branches> deploys automatically — treat that push as a release"; one sentence with "except" reads right. The CLAUDE.md
  git line (template line ~80, en and th) has the same layout
- 19/N-c — with `push: allowed` the push rule does not mention the protected branches CLAUDE.md lists

[setup-choices rule 27](../../../specs/setup-choices.md#setup-flow-and-generated-files).

## What to do

- `templates/agents/release-operator.md` (English only — agent templates have no th copy): `description` and the
  "Before anything live" steps depend on `deployOwner` (owner order) vs allowed (check the change against
  `policies.deploy.target` / `exceptions`); the push rule: `pushOwner` → as today; allowed → "Pushing is allowed" +
  `{{#if policies.autoDeployBranches}}, except to … — that push deploys automatically and counts as a release{{/if}}` +
  the protected branches when set; drop the separate auto-deploy bullet
- the CLAUDE.md git line (en, th): with push allowed and auto-deploy branches, the same "except" order
- list each sentence you change with the template variable or `config.mjs` / `generate.mjs` line that makes it true,
  in the verify notes (the T-M2-28 practice that passed review at the first round)
- `test/unit/release-operator-text.test.mjs`: SETUP-AC-14 (id in the name); render through `generate` in temp folders
- this repository's own `.claude/agents/release-operator.md` and `CLAUDE.md` do not change (push and deploy are
  `owner-order` here) — the test proves the owner-order text is unchanged
- `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api`, then restore
  `examples/todo-api/.claude` and `examples/todo-api/package.json`
