# T-M3-39 — refresh-copies test fixture on Windows + Node 20

## Why

Friction F-018: the only failing CI job of run 45659704061 is `windows-latest · node 20` (also in run 45560880247 and on a
re-run — deterministic): COPIES-AC-10 and -11 fail with `check: copies differ from kit/` listing every file of the
**real** `examples/todo-api/tools/saf` as `extra`. Their fixture `exampleCopy()` copies the real example with
`cpSync(..., { filter })` meant to skip the example's `tools` and `node_modules` folders (filter uses
`relative(...).split(sep)[0]`); on that platform the engine folder arrives anyway. The exact cause inside `cpSync` is
**not proven** (no Windows machine here), so the fix does not rely on the filter: remove the two folders after the copy
and split on both separators. The CI run of the merged commit is the proof.

## What to do

- `test/unit/refresh-copies.test.mjs` `exampleCopy()`: split the relative path on both `/` and `\`, and right after
  `cpSync` remove `${EX}/tools` and `${EX}/node_modules` from the copy (`rmSync(..., { recursive: true, force: true })`),
  then put the fake engine file as before. Assertions stay as they are
- nothing else; do not weaken any assertion

## Out of scope

- the script itself · any other test
