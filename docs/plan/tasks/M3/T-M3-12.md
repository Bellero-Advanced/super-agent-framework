# T-M3-12 — CHANGELOG catches up M2 and M3

## Why

`## Unreleased` is empty although M2 and M3 changed a lot that users see; `task:release` computes the version from
that section and refuses an empty one ([spec rule 7](../../../specs/auto-release.md#taskrelease-m--dry-run-default)).
The live 0.1.0 predates today's code, so the next release is 0.2.0 (D-015).

## What to do

- read the done cards of M2 and M3 (titles, evidence, `docs/plan/reports/M2.md` if it exists) and write one line per
  user-visible change under `## Unreleased` in `### Added` · `### Changed` · `### Fixed` (Keep a Changelog style of
  the 0.1.0 entry); include at least: test mode and `task:culprit`, the setup choices interview and `saf choices`,
  `saf upgrade` adding missing scripts to `package.json` (Changed), guided setup re-run with `--dry-run`/`--diff`/
  `--keep`, the HTML evidence report, document languages, the card size check, the friction log, `task:review`,
  effort by size, self-fix cards, `task:release`, card sizes M and L with the hard stop and L cards in steps
  (T-M3-35 … T-M3-37)
- the size change is the known `### Breaking` candidate: a `planned` milestone's S card (or one without size) is now a
  plan issue, and an old `{ S, M }` `workflow.sizes` / `workflow.testCaps` is ignored — name it to the main session
- no `### Breaking` section unless a card changed behaviour in a way an existing user must act on; if one did, name it
  and ask the main session (it decides whether the owner must see it) — a Breaking section at 0.x still gives a minor
  bump
- engine and product files stay untouched

## Out of scope

- skill packs (T-M3-13, T-M4-01 and T-M4-02 add their own lines) · releasing

## Done when

- `node -e "const s=require('fs').readFileSync('CHANGELOG.md','utf8');const u=s.split(/^## /m).find(x=>x.startsWith('Unreleased'))||'';for(const w of ['task:culprit','task:friction','task:review','task:release','saf choices','package.json'])if(!u.includes(w))process.exit(1)"`
- `node --input-type=module -e "import { readFileSync } from 'node:fs'; import { readChangelog, nextVersion } from './tools/saf/lib/release.mjs'; const v = nextVersion('0.1.0', readChangelog(readFileSync('CHANGELOG.md','utf8'))); if (v !== '0.2.0') { console.error(v); process.exit(1) }"`
- `npm run docs:check`
