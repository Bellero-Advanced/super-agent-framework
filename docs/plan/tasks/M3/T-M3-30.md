# T-M3-30 — Designer pre-run

## Why

A check that already passes before the card proves nothing. The first LCAP-AC-04 row (base 65000, step 100,
`lanes.code` 3) could never fail and nobody noticed until review (M2 review note 25/N1). While planning these cards a
second case showed up: `npm run saf:refresh -- --check` exits 0 today because the current `upgrade` ignores the flag
and simply runs — so T-M3-27 proves `--check` with its test instead. Owner order 2026-11-24. Text in the designer
agent and templates (en, th) — **role effort: high** for the text part.
[Spec rules 1–10](../../../specs/designer-prerun.md#2-rules) — rule 10 says why `task:state` / `spec:matrix` get no
automatic warning (false positives without running every command).

## What to do

- new `kit/tools-saf/lib/prerun.mjs`: read the card's "Done when" items with their raw text (the card file; the plan
  loader stays unchanged), classify (rule 6; the engine-check script list as one table), print the plan, run the
  non-guards with the engine runner `task:verify` uses, exit per rule 8; writes nothing
- `bin/saf.mjs`: `task prerun <id>`, strict arguments (exit 2); `config.mjs` `ENGINE_SCRIPTS["task:prerun"]`;
  `generate.mjs` `cmd.taskPrerun`; `package.json` script; example `package.json` through `npm run saf:refresh` (the
  card's `touch` keeps it)
- `templates/agents/designer.md`: the rule of rule 1 (no project-specific example); kit card templates en + th and
  `docs/plan/tasks/_template.md`: the "Done when" line of rule 3; kit spec templates en + th and
  `docs/specs/_template.md`: the Acceptance line; `/saf-plan` en + th: step 3 runs `task:prerun` for each new card
- this repository's `.claude/agents/designer.md` and `.claude/commands/saf-plan.md`: the rendering with
  `saf.config.json` (when T-M3-29 has landed, its AC-03 test still passes — `npm test` runs it)
- `test/unit/designer-prerun.test.mjs`: PRERUN-AC-01 … -06 (ids in the names), temp repos with fake commands
  (`node -e "process.exit(1)"`)
- in the verify notes: sentence → code for every added template sentence

## Out of scope

- An automatic warning in `task:state`, `spec:matrix` or the hook (rule 10) · blocking `task:start`

## Done when

- `node --test test/unit/designer-prerun.test.mjs test/unit/generate.test.mjs`
- `npm run saf:refresh -- --check` — passes by design: guard that the engine copies equal kit (T-M3-27)
- `npm run spec:matrix -- --check`
- `npm test`
- `npm run check-secrets`
- `npm run docs:check`
