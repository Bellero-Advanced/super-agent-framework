# T-M3-04 — task:start names the agent; effort in evidence, summary and report

## Why

Variant agent files only help when the main session knows which one to use for a card, and D-016 is only judged
fairly when the report puts effort next to review rounds. [Spec rules 5, 11–12](../../../specs/effort-by-size.md#shown-and-measured).

## What to do

- `task.mjs` `startCard`: call `cardEffort`; store `started.effort: { agent, effort, mode, source }` (main-folder and
  lane starts); `bin/saf.mjs` prints the line of rule 11 after a start, plus the warning when `cardEffort` returns one
- `plan.mjs` `doingLines` + `text.mjs` (en, th): the agent on the in-progress card's line in the session summary and
  the lane summary
- `report.mjs` + `text.mjs`: the "Effort and review rounds" table of rule 12 (rounds from `readReviews` of T-M3-02;
  cards without `started.effort` in the `—` row)
- `/saf` templates (en, th): the build step says "the agent `task:start` named" instead of "the card's role agent";
  `/saf-plan` templates (en, th): large design (a new spec file or a decision row affecting more than one card) →
  `designer`, other plan work → the designer's variant from `variantAgents` (rule 5); `generate.mjs` `templateData`
  passes the mode and that name (no new config key), and the text shows only in `by-size` mode; CLAUDE templates
  (en, th): the "effort fixed per role" phrase becomes conditional (by-size → "effort by card size")
- `docs/card-lifecycle.md`: where the agent name comes from
- `test/unit/effort-shown.test.mjs`: one test per scenario id in its name; the existing summary and report tests
  stay green
- run `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api`, then
  `git checkout -- examples/todo-api/.claude`
