# T-M3-27 — One command refreshes every engine copy

## Why

Friction **F-001** (open since M2): every kit card runs `npm run saf:refresh`, then
`node bin/cli.mjs upgrade --dir examples/todo-api`, then restores `examples/todo-api/.claude` and
`examples/todo-api/package.json` by hand — about sixty card prompts in M2 and M3 carried those lines, and M2 review
notes T-M2-10 C and T-M2-12 8 are a stale example copy restored by hand. The dogfood unit test catches stale copies
only in the full suite at merge. Owner order 2026-11-24 (efficiency, quality unchanged).
[Spec rules 1–11](../../../specs/refresh-copies.md#2-rules). Repository-only: `scripts/` does not ship.

## What to do

- new `scripts/refresh-copies.mjs` per rules 1–9: a data table at the top (example folder, excluded globs, compared
  folder pairs); the card from `kit/tools-saf/lib/` (`loadPlan`, `activeCards`, `laneFolder`; touch matching with
  `globToRegExp` as `task:verify` does); snapshot → upgrade (b) → restore; `--check`; export the steps so the test can
  replace both upgrades with a fake (spawn helper takes `process.execPath` and an argument array)
- `package.json`: `"saf:refresh": "node scripts/refresh-copies.mjs"`
- `saf.config.json`: `npm run saf:refresh -- --check` first in `workflow.mergeChecks` (rule 10)
- `CLAUDE.md` ("This repository is SAF itself"): the refresh line says it refreshes both copies and restores the
  example files outside the card's `touch`; one line that kit cards list `npm run saf:refresh -- --check` in "Done when"
- `CONTRIBUTING.md` lines 30 and 54: one command; keep the words `upgrade --dir examples/todo-api` (the doc test checks
  them)
- `test/unit/refresh-copies.test.mjs`: COPIES-AC-01 … -08 (ids in the names) in temp folders; AC-08 reads this
  repository's files. Every new test must fail on the code before this card (the agent's "Before you report")
- the main session, after the card lands: `npm run task:friction -- close F-001 fixed T-M3-27` and commit the friction
  file alone

## Out of scope

  refresh lines in older cards (M3 scope says the one command replaces them)
