# T-M3-33 — generated files stay equal to the templates

## Why

Friction F-009 and review note Q8 of T-M3-31: this repository's `.claude/commands/saf.md` is kept as "edited in this
project" by every upgrade and is hand-edited on each template change; `CLAUDE.md` misses the `task:culprit` line; the
example's `/saf` commands, three agents and `CLAUDE.md` are stale (also note A4 of T-M3-29). Root causes: the root
`.saf/manifest.json` is reverted by hand on every card (old hashes → "edited"), and the example restore puts back every
`.claude/**` file. [Spec rules 12–18](../../../specs/refresh-copies.md#generated-files-stay-equal-to-the-templates-t-m3-33-f-009).
F-009 is logged as `workaround`, so this is a designer card (not a D-017 self-fix).

## What to do

- `scripts/refresh-copies.mjs`: the table's `engineGlobs` becomes the list of example files SAF owns (rule 12) used by
  the restore; after step (b) the example re-render of rule 13 (`planSetup` from `kit/tools-saf/lib/generate.mjs`,
  only `CLAUDE.md` and `.claude/agents/*` with action `update`, manifest hash per key with setup's hash function —
  sha1 of the content, as `generate.mjs` `sha`), output `example re-rendered: <n>` and `kept (edited): <path>`;
  a throw in the re-render stops, restores and exits 1 naming the step
- `saf.config.json` `workflow.alwaysAllowed`: add `.saf/manifest.json` and the rule-12 example globs not already there
- `test/unit/refresh-copies.test.mjs`: reword the COPIES-AC-01 and -02 tests to the new files of the spec rows
  (`.claude/settings.json`, `docs/new.md`, `README.md`); add COPIES-AC-09 … -12 (AC-10/11 on a temporary copy of the
  example with the fake upgrades)
- `test/unit/repo-sync.test.mjs`: COPIES-AC-13 … -15 (sync tests of rules 15–17); AC-14 prints the rendered block on
  failure
- `CLAUDE.md`: make the Commands block equal the rendering (rule 16 — keep the narrow comment column); one line in
  "This repository is SAF itself": a unit test keeps `.claude/commands`, `.claude/skills` and the Commands block equal
  to the templates, so a kit card that changes the commands block lists `CLAUDE.md`
- run `npm run saf:refresh` (writes the root and example manifests, re-renders the example) and commit the result

## Out of scope

- Writing this repository's `CLAUDE.md` or agents from the script · the example's other generated docs ·
  the `.gitignore` pair (F-006) · `--check` reporting the example re-render
