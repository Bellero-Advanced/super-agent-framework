# T-M1-03 — Upload the social preview image

## Why

Links to the repository (chat, social posts) show the preview image instead of a generic card.

## What to do

1. Owner: GitHub → repository Settings → General → Social preview → upload `docs/assets/social-preview.png`
   (1280×640). GitHub has no API for the upload, so this step is the owner's
2. If the owner wants a change to the image: edit `social-preview.svg`, render it at 1280×640 to the PNG, upload again

## Done when

- `node scripts/release-check.mjs social`
