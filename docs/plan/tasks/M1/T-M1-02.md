# T-M1-02 — Tag v0.1.0 and publish the GitHub release

## Why

People find releases on GitHub first; the release notes say what 0.1.0 is and how to install it.

## What to do

1. On the owner's order: tag the published commit `v0.1.0` and push the tag
2. `gh release create v0.1.0` with the 0.1.0 section of `CHANGELOG.md` as the notes and the quickstart on top

## Out of scope

- Any code change — the release is exactly what npm has

## Done when

- `node scripts/release-check.mjs tag`
- `node scripts/release-check.mjs release`
