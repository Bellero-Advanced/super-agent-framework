# T-M1-01 — Publish super-agent-framework and create-saf 0.1.0 to npm

## Why

`npx create-saf` is the quickstart on the README; it only works once both packages are on npm.

## What to do

1. Owner: `npm login` (an npm account with two-factor auth; the release-operator never handles the credentials)
2. On the owner's order: `npm test`, then `npm pack --dry-run` in the root and in `packages/create-saf` — check the
   file lists (no `test/`, `examples/`, `tools/`, `.claude/`, `docs/`)
3. `npm publish` in the root first, then `npm publish` in `packages/create-saf`
4. `CHANGELOG.md`: give the 0.1.0 entry its release date

## Out of scope

- The git tag and the GitHub release (T-M1-02)

## Done when

- `node scripts/release-check.mjs npm`
- `npm run test:package`
