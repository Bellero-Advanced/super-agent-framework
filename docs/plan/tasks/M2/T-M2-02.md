# T-M2-02 — Show what /saf-setup would change before regenerating project docs

## Why

Re-running setup archives edited files and replaces them; people want to see the change first.

## What to do

- A dry-run mode of generate that returns, per file: new · unchanged · would replace · would archive (edited), with a diff
- `/saf-setup` shows that list and asks once before writing
- Tests: dry run writes nothing; the list matches what the real run does
