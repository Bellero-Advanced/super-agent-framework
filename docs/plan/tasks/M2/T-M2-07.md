# T-M2-07 — task:verify runs the card's own tests instead of the full suite when the test mode defers it

## Why

The full suite on every card verify is the slowest step on a weak machine. In `milestone` and `targeted` mode a card
proves itself with the tests it touches, and its evidence says plainly that the full suite is still owed —
[spec rules 9–17](../../../specs/test-mode.md#card-verify-taskverify-card).

## What to do

- new `kit/tools-saf/lib/testmode.mjs`:
  - `isFullSuite(config, cmd)` — rule 9 (`FULL_SUITE_KEYS`)
  - `defersAtVerify(config, inLane)` — the verify column of the rule 15 table
  - `targetedFiles(root, card, changedFiles)` — rule 10: changed test files (`isTestFile`) that exist + files that hold
    one of the card's scenario ids (`findScenarioTests` from `scenarios.mjs`)
  - `targetedCommand(config, files)` — `stack.commands.testFiles` with `{files}` replaced, each path quoted
    (`quoteWindowsArg` on Windows, single quotes elsewhere); `null` when the command is empty or no files
- `verifyCard` in `task.mjs`: split `card.criteria` into full-suite and other commands; when the mode defers and a
  targeted command exists, run the others plus the one targeted run; otherwise run every criterion (rule 13 fallback,
  reason recorded). Files are listed before the targeted run so the selection uses the card's real changes
- evidence `verified`: `testMode: { mode, source }` always; `deferred` and `targeted` (`{ files }` or `{ fallback }`)
  when it applies — rule 16
- verify output: `! full suite deferred to gate (test mode <mode> from <source>): <commands>`
- `verifySummary` in `plan.mjs` appends the "full suite deferred to gate" text from `text.mjs` (en + th) for a passed
  card with `deferred` — STATE.md and the session summary pick it up
- run `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api` after changing `kit/`
- tests in `test/unit/test-mode-verify.test.mjs` on temporary repos (`ctx.run` stubbed to record commands), named
  with the scenario ids

- choosing tests from changed source files (spec §6)
