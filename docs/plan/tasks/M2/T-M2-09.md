# T-M2-09 — task:culprit finds the card that broke the deferred full suite

## Why

Deferring the full suite to the gate loses "which card broke it". A binary search over the milestone's commits gets
it back in a few runs instead of one run per card —
[spec rules 21–27](../../../specs/test-mode.md#finding-the-card-that-broke-the-suite-taskculprit-m).

## What to do

- new `kit/tools-saf/lib/culprit.mjs` — `findCulprit(ctx, mid, { cmd })`:
  - refuse in a lane (`refuseInLane`); error when no card of the milestone has started
  - base = oldest `started.base` of the milestone's cards that is an ancestor of HEAD; commits =
    `git rev-list --first-parent --reverse base..HEAD`
  - one temporary detached worktree under `workflow.worktreeDir` (`git worktree add --detach`), moved with
    `git checkout --detach <sha>` per step; `workflow.laneInstall` before each run when set; runs through
    `taskRunner(worktree, …)` with the same timeout as verify; removed in `finally` (`git worktree remove --force`, then
    `git worktree prune`)
  - HEAD passes → exit 3 · base fails → exit 2 · else binary search; map the first failing commit to a card (id in the
    subject, else largest overlap with evidence `files.changed`, else "no card")
  - report: card id + title · commit + subject · last lines of the failing run · runs used; warn when the main folder
    has uncommitted changes (not tested); write nothing in `docs/plan/`
- `bin/saf.mjs`: `task culprit <M> [--cmd "<command>"]` with exit codes 0 / 2 / 3 (1 = error)
- `config.mjs`: `"task:culprit": "task culprit"` in `ENGINE_SCRIPTS`; `generate.mjs`: `taskCulprit: c("task:culprit", "<M>")` in the
  `cmd` table next to `taskReport` (T-M2-10 uses it in templates); this repo's `package.json` gets the script
  (`saf:refresh` merges it — check it is there)
- `verifyMilestone` in `task.mjs`: when a gate with a full-suite command fails and `deferredCards` is not empty, print
  the hint `task:culprit <M>` (rule 21) with the project's script runner (`cmd()`)
- run `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api` after changing `kit/`
- tests in `test/unit/culprit.test.mjs` on a temporary repo with four card commits (the check is a `node -e` that
  fails when a marker file exists), named with the scenario ids; assert the run count and that the worktree is gone

## Out of scope

- fixing the culprit or reopening its card — the report names it; the designer writes a fix card
- user docs (T-M2-10)
