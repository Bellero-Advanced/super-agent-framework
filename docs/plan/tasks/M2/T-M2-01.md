# T-M2-01 — Add a document language by adding a template folder and a text table

## Why

Generated docs and status text exist in English and Thai only; teams in other languages read rules in a second language.

## What to do

- Make the language list data-driven: a template folder plus a text table registers a language
- Fall back to English for any missing template, with a docs:check warning
- Tests: a fixture language renders, a missing template falls back

## Out of scope

- Anything not named above — its own card

## Done when

- `npm test`
- `npm run docs:check`
