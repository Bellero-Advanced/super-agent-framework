# T-M2-01 — A document language is one text-table entry plus a template folder

## Why

Adding a language today means edits in five places with nothing to say what was missed (a language-name table and a
Thai-only branch in `generate.mjs`, three schema enums, the setup explanations, the interview file). One registry and
an English fallback let a contributor add a language and see exactly what is still English.
[Spec rules 1–11](../../../specs/doc-languages.md#2-rules). No third language ships here (D-014).

## What to do

- `kit/tools-saf/lib/text.mjs`: `langName`, `names` and `sessionWork` (the three session-table labels) in `en` and
  `th`; export `LANGUAGES = Object.keys(TEXT)`, a `mergeText(base, table)` that merges nested objects key by key, and
  a `textFor` built on it; a `languageName(code, docLang)` helper (rule 2)
- `kit/tools-saf/lib/generate.mjs`: drop `LANG_NAME` and the `docLang === "th"` branch of `sessionRows` (use the text
  table); drop `isTh` and `chatTh` from the template data (no template uses them); in `plannedFiles` read each document from `templates/<lang>/` or, when missing, from `templates/en/` and add
  the warning of rule 4 to the report (keep the warning path compatible with `planSetup` from T-M2-02)
- `kit/tools-saf/lib/choices.mjs`: values of the `chat-language` / `doc-language` entries = `LANGUAGES`; the
  `report-language` entries become `en` + one entry for every other language, with the current Thai entry reworded so
  it names no language (en and th text; ≤ `FIELD_MAX`, no digit runs)
- `kit/claude/skills/saf-setup/questions.md`: option column of the three language rows → the languages `choices`
  lists (Key column unchanged, so SETUP-AC-02 holds)
- `CONTRIBUTING.md`: section "Add a document language" (rule 10)
- `test/unit/doc-languages.test.mjs`, names with the scenario ids; AC-02/03 copy `kit/tools-saf` to a temp folder,
  add the `xx` entry to the copy's `text.mjs` (string edit), one template file and the enum values in the copy's
  schema, then import the copy's `generate.mjs` / spawn the copy's `bin/saf.mjs choices`
- run `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api`, then
  `git checkout -- examples/todo-api/.claude examples/todo-api/package.json`

## Out of scope

- a third language (contribution with a native reviewer) · explanation text in more languages · agent, rule and skill
  templates
