# T-M2-17 — STATE.md, the plan mirror and the milestone report show the full-suite gate and its result

## Why

The extra `full-suite` gate lives only in the milestone evidence. STATE.md, `.saf/plan.md` and `task:report <M>` loop
over the gates of the milestone file, so a milestone whose full suite failed at the gate can look all green everywhere
except the `task:verify <M>` output —
[spec rules 29–30](../../../specs/test-mode.md#the-full-suite-gate-in-the-plan-files).

## What to do

- `text.mjs` (en and th): `fullSuiteGate` — the text of the `full-suite` gate · `undeclaredGate` — "not in the
  milestone file". `testmode.mjs`: `FULL_SUITE_GATE.text` reads the en entry, so the text has one home
- `plan.mjs`: export `undeclaredGates(plan, m)` — the gates of `plan.gateEvidence.get(m.id)` whose id is not in
  `m.gates`, in evidence order, each `{ id, text, pass }` with the text from the doc-language text table
  (`fullSuiteGate` for `FULL_SUITE_GATE.id`, `undeclaredGate` otherwise)
  - `renderState`: show the exit-gate table when the milestone has declared or undeclared gates; after the declared
    rows add one row per undeclared gate, marked like a declared gate (`gatePass(time)` · `gateFail` · `gateManual`
    when `pass` is null)
  - `renderMirror` "Done When": one `- [x]` / `- [ ]` line per undeclared gate after the declared ones
- `report.mjs` gate table: the same rows after the declared ones, marked as declared gates are marked there
- the views read only the milestone evidence, never `config.workflow.testMode` (rule 30) — no evidence → only the
  declared gates, output unchanged from today
- new `test/unit/test-mode-gate-views.test.mjs`, named TMODE-AC-16: a plan with milestone evidence holding a failed
  `full-suite` gate and a passed gate `old` not in the milestone file; for `docLanguage` en and th assert STATE.md,
  `.saf/plan.md` and the report each have a `full-suite` row with the text-table text and the failed mark, and an `old`
  row with the "not in the milestone file" text; with no milestone evidence the gate rows equal the declared gates
- run `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api` after changing `kit/`, then
  `npm run task:state` (STATE.md layout is unchanged while this repo has no M2 evidence)

## Out of scope

- which gates run and the reserved id (T-M2-16)
- the session summary (it lists no gates today) and the evidence viewer (T-M2-05, which reads the evidence files
  directly)
- the `task:verify <M>` CLI output — it already prints every evidence gate
