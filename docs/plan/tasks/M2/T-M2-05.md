# T-M2-05 — task:report <M> --html writes one self-contained HTML page

## Why

Owners who do not read JSON still want to see what each card ran and why it passed. The evidence already holds it;
a page that opens offline, with no JavaScript and no dependency, shows it. [Spec rules 1–9](../../../specs/evidence-viewer.md#2-rules).

## What to do

- new `kit/tools-saf/lib/viewer.mjs`: `renderEvidencePage(plan, mid)` (pure) and `htmlPath(mid)` (next to
  `reportPath`); one `esc()` used for every value from the plan or evidence; inline `<style>`, the CSP meta tag of
  rule 3, `<details>` per card; content and order per rules 5–6; reuse `cardStatus`, `titleOf`, `undeclaredGates`,
  `formatTime` from `plan.mjs`; deterministic (rule 8 — show the newest evidence time, never "now")
- `kit/tools-saf/lib/text.mjs`: a new `viewer` object of labels in **both** `en` and `th` (the `th` table spreads
  `en` one level deep only, so nested labels must exist in both)
- `kit/tools-saf/bin/saf.mjs` `task report`: `--html` also writes the page and prints its path; usage line and
  header comment updated
- one line each in `docs/card-lifecycle.md` (step 31) and the en/th plan README templates (the line with
  `{{cmd.taskReport}}`): add `--html` writes a page for people who do not read JSON
- `test/unit/evidence-viewer.test.mjs`: plan objects built in the test (or a temp project with evidence files), one
  test per scenario id in its name; AC-02 also asserts no `<script`/`<link`/`<iframe` and no `src=`/`href=` to
  `http:`/`https:`/`//`
- quick pass of the `security-review` skill (level 1: unescaped HTML output) before verify
- run `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api`, then
  `git checkout -- examples/todo-api/.claude examples/todo-api/package.json`

## Out of scope

- a multi-milestone site, JavaScript, charts · any change to what evidence records
