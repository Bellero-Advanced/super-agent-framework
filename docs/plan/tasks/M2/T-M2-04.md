# T-M2-04 — task:verify reports changed code and test lines against the card's size cap

## Why

Size caps (S ≤ 150 code lines, tests ≤ 250) are written on every card but nothing measures them.

## What to do

- Count added + removed lines from the start commit, split into code and test files (test globs from the config)
- Over the cap: a warning in the verify output and in the evidence (not a failure — the reviewer decides)
- Tests: a card under the cap, one over, test lines counted apart

## Out of scope

- Anything not named above — its own card

## Done when

- `npm test`
- `npm run docs:check`
