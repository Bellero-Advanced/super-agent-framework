# T-M2-10 — /saf-setup asks for the test mode and the docs explain the three modes and task:culprit

## Why

A setting nobody knows about saves nobody time. New projects pick a mode in the interview, and every person learns
how to override it on their own machine — [spec §2](../../../specs/test-mode.md#2-rules).

## What to do

- `kit/claude/skills/saf-setup/questions.md` §6 Workflow: two rows — "How often should the full test suite run?"
  (`workflow.testMode` · every-card · targeted · milestone · recommended **milestone**, the fastest; say that each
  person can override it in `saf.config.local.json` or `SAF_TEST_MODE`) and "Command that runs only some test files"
  (`stack.commands.testFiles` · recommend from the test runner, e.g. `node --test {files}` · `vitest run {files}` ·
  `pytest {files}` · empty = cards fall back to the full suite)
- `SKILL.md`: when the person's machine is slow or fast, offer to write `saf.config.local.json` with only
  `workflow.testMode` (never other keys — LOCAL_KEYS)
- `docs/card-lifecycle.md`: section "Test mode" — the rule 15 table, what a card's evidence carries ("full suite
  deferred to gate"), the gate, `task:culprit` and its exit codes; link the spec rules, do not copy the tables of
  `config.mjs`
- `docs/config-reference.md`: rows `workflow.testMode`, `stack.commands.testFiles`, and a short `saf.config.local.json`
  section (precedence env → local → repo → default)
- `docs/setup-questions.md` §6 list: add "test mode"
- plan README templates (en + th) and this repo's `docs/plan/README.md`: one line in §1 and §5 naming `workflow.testMode` — merge checks skip the
  full suite in `milestone` mode; the gate runs it; `task:culprit` on a failed gate
- CLAUDE templates (en + th): add `{{cmd.taskCulprit}}` (added by T-M2-09) to the command list (this repo's own CLAUDE.md is not
  regenerated by this card)
- `README.md` / `README.th.md`: one sentence each in the feature list
- `test/unit/generate.test.mjs`: the generated CLAUDE.md (en and th) lists `task:culprit`
- run `npm run saf:refresh` after changing `kit/claude/skills/saf-setup/`
