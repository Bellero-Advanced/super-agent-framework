# T-M2-21 — --diff shows each change, --keep keeps an edited file

## Why

A list says that `CLAUDE.md` would be archived and replaced, not what changes in it. The person needs the diff to
decide, and a way to say "keep mine" for that one file without editing answers.
[Spec rules 6–7, 14–15](../../../specs/setup-rerun.md#seeing-it-first).

## What to do

- new `kit/tools-saf/lib/diff.mjs` (no dependency): `diffLines(a, b, { context })` → unified hunks
  (`@@ -l,n +l,n @@`, ` `/`-`/`+` lines) from a longest-common-subsequence line diff; `unifiedDiff(path, a, b)` adds
  the `--- a/<path>` / `+++ b/<path>` headers; `DIFF_LIMITS` holds the context lines and the line limit — over the
  limit, one line with both line counts
- `kit/tools-saf/lib/generate.mjs`: `planSetup` takes `opts.keep` (list of paths): each planned rendered path in it is
  `keep-edited` (not written, manifest entry unchanged); a path that is not planned → error naming it; planned actions
  carry the current and the new text for `update` · `replace-edited` · `keep-edited` and `saf.config.json`
- `kit/tools-saf/bin/saf.mjs` `setup`: `--keep <path>` (repeatable, comma-separated allowed; unknown path → exit 2
  naming it), `--diff` with `--dry-run` prints the diffs after the list; `--diff` alone → exit 2 with the usage line
- `test/unit/setup-diff.test.mjs`, names with the scenario ids (AC-05: CLI diff of an edited `CLAUDE.md`, a known
  text pair → expected hunk, an over-limit file → one line; AC-06: `--keep CLAUDE.md` then a second dry run, and the
  two exit-2 cases)
- run `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api`, then
  `git checkout -- examples/todo-api/.claude examples/todo-api/package.json`
