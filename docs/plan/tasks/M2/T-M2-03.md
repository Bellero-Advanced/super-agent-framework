# T-M2-03 — Skill-pack format and saf pack show

## Why

Teams have their own skills and want one copy shared across projects. A pack is third-party text that agents will
follow, so the first step is a strict format and a read-only command that shows every file, every requested tool and
the content hash before anything is installed. **Security-relevant:** build and review with the `security-review`
skill (level 1 while building; the spec-reviewer checks the [trust model](../../../specs/skill-packs.md#2-trust-model)).
[Spec rules 1–7](../../../specs/skill-packs.md#3-rules).

## What to do

- new `kit/tools-saf/lib/packs.mjs` (no dependency, no `child_process`, no dynamic `import`):
  - `PACK_LIMITS` (files, bytes) and the name pattern as data
  - `readPack(dir, { taken })` → `{ ok, name, version, description, skills: [{ name, description, tools, files }],
    files, refused, problems }`: parse `saf-pack.json`; walk with `lstat` (any symlink → problem); keep only regular
    `.md` files under listed `skills/<skill>/`, everything else → `refused`; check `SKILL.md` frontmatter (reuse
    `frontmatter` from `markdown.mjs`); clashes with `CORE_SKILLS`, `SKILL_PACKS`, `saf-setup` and `taken`
  - `packHash(dir, files)` per rule 6 (sorted POSIX paths, LF-normalised text, zero-byte separators, sha256)
- `kit/tools-saf/bin/saf.mjs`: `pack show <path>` prints rule 7's output and the `skills.external` entry; exit 0 /
  1 / 2; writes nothing; usage line and header comment
- `docs/skills.md`: section "Packs from other repositories" — the format, the trust model in plain words (a skill is
  instructions; SAF never fetches or runs anything; pin the source with a git submodule and the content with the hash),
  `pack show`; describe only what this card ships (T-M2-23 adds the install steps to the same section)
- `test/unit/skill-packs.test.mjs`: fixture packs built in temp folders (symlink case skipped where the OS refuses
  symlinks, with the reason in the skip message); one test per scenario id in its name; AC-01 checks no file appears
  in the pack folder or the cwd
- run `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api`, then
  `git checkout -- examples/todo-api/.claude examples/todo-api/package.json`
