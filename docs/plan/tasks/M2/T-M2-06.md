# T-M2-06 — Choose how often the full test suite runs, per project and per machine (workflow.testMode)

## Why

Machines differ: the owner's machine is slow, CI is not. The mode must be a setting each person can change without
changing the tracked config — [spec §2 rules 1–8](../../../specs/test-mode.md#settings). Decision D-008 (decided).

## What to do

- `kit/tools-saf/lib/config.mjs`: tables `TEST_MODES` (`every-card` · `targeted` · `milestone`), the default mode
  (`milestone`), `LOCAL_KEYS` (`["workflow.testMode"]`), `FULL_SUITE_KEYS` (`["test", "e2e"]`), the env name
  `SAF_TEST_MODE`, and `LOCAL_CONFIG_FILE = "saf.config.local.json"`
- `loadConfig(root, env = process.env)` (engine runs only): after validating `saf.config.json`, read
  `saf.config.local.json` if present — refuse keys outside `LOCAL_KEYS` (error names the key), validate with the schema
  — then apply `SAF_TEST_MODE` (invalid value → error listing `TEST_MODES`). Store the result as
  `config.workflow.testMode` and its source as `config.workflow.testModeSource` (`env` · `local` · `repo` · `default`)
- `resolveConfig` (used by the generator) keeps reading only what it is given — generated files never see local values
- schema: `workflow.testMode` (enum from the table — keep schema and table in step, a unit test compares them) ·
  `stack.commands.testFiles` (string, may contain `{files}`)
- `generate.mjs`: add `saf.config.local.json` to `GITIGNORE_LINES`
- this repo (D-008): `saf.config.json` sets `"testMode": "targeted"` and `"testFiles": "node --test {files}"`;
  `.gitignore` gains `saf.config.local.json`. Reason: this repo changes the engine that writes the evidence, so every
  card still gets one full run before it reaches `main` (see M2 Risks)
- after changing `kit/`: `npm run saf:refresh` and `node bin/cli.mjs upgrade --dir examples/todo-api` (the copies are
  in `workflow.alwaysAllowed`, D-007)
- tests in `test/unit/test-mode-config.test.mjs` named with the scenario ids

## Out of scope

- any change in what verify, merge or the gate run (T-M2-07, T-M2-08) — until those land every mode behaves like
  `every-card`
- the setup question and user docs (T-M2-10)
